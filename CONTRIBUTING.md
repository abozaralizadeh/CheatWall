# Contributing

CheatWall is source available under the [PolyForm Noncommercial License 1.0.0](LICENSE). It is free to use and study for non-commercial purposes. It is not open source in the strict sense, because commercial use is not allowed without written permission.

## Before you send a change

- Open an issue first for anything big, so we can agree on it.
- Run `npm test` and `npm run typecheck`.
- Keep the AI provider behind its small module in `src/ai/`.
- Never commit real keys, tokens or a `.env` file.
- Keep text plain and short.

## Contributions and licensing

A contribution is accepted only if you agree that Abozar Alizadeh may relicense it, including for commercial use. By opening a pull request you confirm that you wrote the change (or have the right to share it) and that you agree to this.

## Commercial use

Commercial use needs written permission. Ask by opening a GitHub issue.
