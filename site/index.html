Big, beautiful cheat sheet posters for anything you study

Type a topic. An AI model writes the cheat sheet, and our own templates lay it out as an A2 poster you can print and hang on your wall.

Quick installHow it works

CheatWall is a working name, and the project is still early. The AI step is only tested with a local fake so far, so real AI quality is not measured yet.

What you get

  • One print-ready A2 portrait PDF with real text, and a PNG preview.
  • Three colour themes. Switching theme redraws the poster with no new AI call.
  • Tables, steps, definitions, formulas (KaTeX) and code blocks, all fitted to one page.
  • No accounts. Each poster has a private link, kept for 30 days by default.
  • A per-person daily limit and a daily spend cap, so a free site cannot run up a bill.
  • Every poster says it was made with AI and should be checked.

How it works

  1. You send a topic, and optionally a level (beginner, student or advanced).
  2. The server checks the input, your daily limit and the spend cap.
  3. A background job checks the topic, writes the poster as structured data, and reviews it in a second pass.
  4. Our templates draw the poster. A headless Chrome measures it, finds the biggest text size that fits one page, and exports the PDF and PNG.

The AI only writes data. An image model never draws words, so every letter is sharp and prints at any size. Topics and AI output are treated as untrusted: everything is escaped, and the poster is rendered in a browser with no network.

Quick install

You need Node 24 or newer and a Chrome or Chromium on the same machine (found automatically, or set CHROME_PATH).

git clone https://github.com/abozaralizadeh/CheatWall.git
cd CheatWall
npm install
cp .env.example .env
npm start

Open http://127.0.0.1:3000. By default it uses the local sample provider, which needs no key and costs nothing. It has handwritten posters for SQL, Spanish verbs and organic chemistry, and a labelled placeholder for any other topic.

Use a real AI model

In .env set PROVIDER=anthropic and ANTHROPIC_API_KEY to your own key. The Anthropic provider is written and tested against a mocked client only, so treat the first real run with care and keep the spend cap low.

Run the tests

npm test            # includes tests in a real browser, a few minutes
npm run typecheck

On a Linux VM

sudo ./setup_service.sh
journalctl -u cheatwall.service -f

The first run installs everything and starts a systemd service. Running it again updates and restarts. Set CHEATWALL_DOMAIN to also set up Caddy for HTTPS. The script has not been run on a real VM yet, so read it before you use it.

Is there an online demo?

No. CheatWall is a server app: it needs Node, a database and a real Chrome to draw the PDF, so it cannot run as a static page. This page is only an introduction. The screenshots above are of the real app.
