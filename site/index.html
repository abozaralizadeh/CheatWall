How it works

From a topic to your wall in three steps.

  1. 1

    Type what you're studying

    A topic and, if you like, a level. That's the whole form.

  2. 2

    It writes, checks and fits

    One AI pass writes the content as structured data and a second pass reviews it. Then the layout finds the biggest text that still fits one page.

  3. 3

    Print it big

    Download a vector PDF at A2, or a PNG. Try another colour theme first if you like.

On the wall

Dense enough to study from. Calm enough to hang up.

Every poster is one page, filled edge to edge, with tables, steps, formulas and code where the topic needs them. Hover or tap one to take it off the wall.

These come from the built-in sample provider, which has handwritten content for these three topics. Posters from a real AI model will read differently.

What you get

Built like a print shop, not a chat window.

Sharp at any size

The AI writes data and our templates draw the poster, so every word is real text in a vector PDF. No image model guessing at letters.

Formulas and code

KaTeX sets the maths and chemistry. Code gets a proper monospace block. Both print as cleanly as the headings.

Three looks, one click

Paper, Midnight and Sunrise. Switching redraws the same content, so it costs nothing and takes seconds.

No account, just a link

Each poster gets a long random private link. There's nothing to sign up for, and posters are deleted after 30 days.

A spend cap that holds

The daily AI budget is checked before every AI call, and each person gets a few posters a day. A free site can't run up a bill overnight.

A renderer with no network

Topics and AI output are treated as untrusted. Everything is escaped and drawn in a Chrome that can't reach the internet.

Install

Running in two minutes.

No key needed to start. The built-in sample provider lets you try the whole flow for free.

Run it on your machine

Then open http://127.0.0.1:3000.

$ git clone https://github.com/abozaralizadeh/CheatWall.git
$ cd CheatWall
$ npm install
$ cp .env.example .env
$ npm start

Use a real AI model

Add your own key to .env and keep the daily cap low for the first runs. This provider has only been tested against a mock so far.

PROVIDER=anthropic
ANTHROPIC_API_KEY=your-key-here
DAILY_CAP_CENTS=100

Put it on a Linux VM

The first run installs everything and starts a systemd service. Running it again updates and restarts. Read the script first: it hasn't been tried on a real VM yet.

$ sudo ./setup_service.sh
$ journalctl -u cheatwall.service -f

You need

  • Node 24 or newer. It runs the TypeScript directly, so there's no build step.
  • Chrome or Chromium on the same machine. It's found on its own, or set CHROME_PATH.
  • Nothing else. SQLite is built into Node, and the fonts come with the packages.

Run the tests

79 tests, some of them in a real browser. A few minutes.

$ npm test
$ npm run typecheck

Straight answers

What it does, and what it doesn't yet.

Can I try it online?

Not yet. CheatWall needs a server and a real Chrome to draw the PDF, so it can't run as a static page. The video at the top is the real app running on a laptop.

Which AI does it use?

Out of the box, a built-in sample provider with no key and no cost. It has handwritten posters for SQL, Spanish verbs and organic chemistry, and a clearly labelled placeholder for any other topic. An Anthropic provider is included, but it has only been tested against a mock so far.

Is the content correct?

AI makes mistakes. A second pass reviews each poster, and every poster says it was made with AI. Check anything important, above all for health, law and money, where a poster is study material and never advice.

Is it free?

The code is source available and free for non-commercial use under the PolyForm Noncommercial License 1.0.0. If you want to use it commercially, ask first by opening a GitHub issue.

Can I take a poster into an exam?

That's up to the rules of your exam. CheatWall is a study aid, and the name is a working name.

Why A2?

It's big enough to read from your desk or across the room, and a vector PDF scales cleanly down to A3 or A4 and up to A1.
